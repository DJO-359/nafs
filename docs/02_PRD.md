# Nafs — Product Requirements Document

Version: 1.0
Status: Official

## Цель продукта

Nafs — это спокойное пространство для одного дня.

Приложение помогает пользователю:

- не забыть важное;
- прожить сегодняшний день осознанно;
- сохранить мысли;
- выбрать намерение на завтра.

---

# Основные разделы

Приложение состоит ровно из четырех разделов.

## ⏰ Напоминания

Назначение:

Не забыть важное.

Функции:

- создать напоминание;
- изменить;
- удалить;
- отметить выполненным.

После выполнения напоминание скрывается.

Архива нет.

Истории нет.

---

## ☀️ Мой день

Главный экран приложения.

Содержит:

- приветствие;
- намерение дня;
- утро;
- работа;
- вечер;
- мысли.

Каждый день начинается с чистого листа.

---

## 📖 Дневник

Позволяет сохранить мысли.

Каждая запись содержит:

- дату;
- время;
- текст.

Записи доступны через календарь.

---

## ⭐ Намерение

Каждый вечер пользователь отвечает:

«Каким человеком я хочу быть завтра?»

Утром намерение отображается в разделе "Мой день".

После окончания дня автоматически исчезает.

---

# Навигация

Нижнее меню состоит из четырех вкладок:

- Напоминания
- Мой день
- Дневник
- Намерение

---

# Уведомления

Разрешены только:

- уведомления о напоминаниях;
- вечернее предложение выбрать намерение.

Других уведомлений быть не должно.

---

# Запрещенные функции

В приложении запрещены:

- streak;
- XP;
- уровни;
- достижения;
- проценты выполнения;
- статистика;
- социальные функции;
- рейтинги;
- соревнование;
- лайки;
- комментарии.

---

# Главный принцип

Каждая новая функция должна делать жизнь пользователя спокойнее.

Если функция вызывает давление или усложняет приложение — она не должна быть реализована.
